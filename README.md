## ✨ Tentang Praktikum

Praktikum 2 merupakan lanjutan dari HTML Dasar.

Pada praktikum ini dipelajari beberapa konsep **HTML Lanjutan**, mulai dari pembuatan tabel, form, berbagai jenis input, semantic HTML, multimedia, hingga validasi form dasar.

> 🌸 **Tujuan utama:** memahami dan menerapkan struktur HTML yang lebih lengkap melalui latihan dan proyek mini.

---

## 📚 Materi Praktikum

### 🌷 01 — Tabel HTML
Membuat tabel untuk menampilkan data mahasiswa menggunakan:

- `<table>`
- `<tr>`
- `<th>`
- `<td>`

### 🌷 02 — Pengembangan Tabel
Mengembangkan tabel menggunakan:

- `<thead>`
- `<tbody>`
- `<tfoot>`
- `colspan`

### 🌷 03 — Form Registrasi
Membuat form registrasi mahasiswa dengan:

- Nama Lengkap
- Email
- Password
- Tanggal Lahir
- Tombol Daftar
- Tombol Reset

### 🌷 04 — Radio Button & Checkbox
Membuat pilihan:

- Jenis Kelamin
- Keahlian

### 🌷 05 — Select & Textarea
Menambahkan:

- Pilihan Program Studi
- Kolom Alamat

### 🌷 06 — Validasi Form
Menerapkan validasi menggunakan:

```text
required
minlength
min
max
type
````

### 🌷 07 — Semantic HTML

Menyusun halaman menggunakan elemen semantic:

```text
<header>
<nav>
<main>
<section>
<article>
<aside>
<footer>
```

### 🌷 08 — Multimedia

Menambahkan multimedia berupa:

🎵 Audio
🎬 Video

menggunakan elemen:

```html
<audio>
<video>
```
